## 실기기 검증 (iPhone 14 Pro, iOS 27.0, 2026-09-29~30)

측정 방법: `xcrun devicectl device process launch --console … com.ryujemu.starindex -diag`로 앱을 실행하고 stderr 진단 줄(2초 간격, 좌표 미출력)을 수집했다. 1차는 Debug 빌드(`a3b60ec`), 2·3차는 Release(-O) 빌드(`a4b6221`)다.

| 게이트 | 결과 | 판정 |
|---|---|---|
| G3 정밀 위치(`whenInUse · full`) | 권한 허용 뒤 `cmMagnetic → cmTrueNorth` 승격. 첫 샘플 0.01~0.11 s, `CMErrorTrueNorthNotAvailable` 0회, 앱 전환 뒤 재시작 정상 | 통과 |
| G3 대략 위치(`whenInUse · reduced`, 「정확한 위치」 끔) | **`cmTrueNorth` 그대로 동작**, 첫 샘플 0.01 s, 오류 0회, 약 68 s 관찰. PLAN D4의 "대략 위치에서 진북 프레임 동작 미확인" 위험이 이 기기에서 해소됨 | 통과 |
| G3 거부·미결정 | 미측정(권한 거부 시 `cmMagnetic` 선택은 `MotionFramePolicy` 단위 테스트로만 확인) | 남음 |
| 방위 정확도(CLHeading) | ±10~89°. 8자 보정 직후 ±10~17°, 보정 전·흔들 때 크게 나빠짐 | 배지 동작 확인 |
| T-P1 북쪽 | 사용자가 북쪽을 향해 멈춘 6 s 동안 레티클 방위 357.9~358.1°(고도 약 −10°), 오른쪽으로 돌자 16°로 증가(동쪽이 시계 방향) | 통과(나침반 앱 대비 정밀 비교는 G2) |
| T-P5 천정 | 폰을 머리 위로 들어 화면이 아래를 보게 했을 때 고도 80.3~**85.2°**로 14 s 유지. 화면을 위로 해 탁자에 두면 −86~−89°(천저) | 통과(부호·규약 일치, 손으로 든 오차) |
| G5 CPU(M0 기준 16.7 ms, 강화 기준 8 ms) | 해질녘 재생 20.2 s 전 구간(매 프레임 스냅샷 재계산): **1,210프레임, work p50 4.4 / p95 6.7 / max 10.1 ms**, 프레임 간격 p95 16.8 ms, max 33.2 ms. 평상시 안정 구간 p95 1.7~6.7 ms. 8 ms를 넘은 창은 앱 시작 직후 첫 1프레임뿐 | 통과 |
| G5 GPU(셰이더 ≤1 ms) | 미측정. 진단 수치에는 GPU 시간이 없음 → R1 첫 주 Instruments | 남음 |
| 발열 | 전 구간 `nominal`(1회 재생 뒤 잠시 `fair`) | 정상 |
| 크래시 | StarIndex 크래시 보고 0건. 2차 세션 종료는 SIGKILL(앱 전환기에서 종료 또는 백그라운드 회수로 추정, jetsam 기록 없음) | 정상 |

실기기에서 발견해 고친 것:
- 위치 권한 알림(`.inactive`)에 센서가 멈춤 → `.background`에서만 정지(`dbded32`)
- 리뷰 확인 결함 21건 + 재리뷰 5건 반영(`dbded32`, `a4b6221`)
